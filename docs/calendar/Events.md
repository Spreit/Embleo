### Event type
Episode Open (0)

"Id" can be left blank.
Character IDs can be entered into "SubId". "pl001,pl003" will have both Leo's and Hugo's icons on the "episode" line. Up to 3 character IDs can be entered.

Game Event (1)

Puts pink "EVENT" line on the calendar that continues until next event

Birthday (2)

If ID is character ID (like "pl001"), it will have a birthday icon with the character portrait (Leo's, in this case)

Annual Event (3)
If it's an annual event, the ID is a number presented as string.

ID ranges from "01" to "11" and "100", according to calendar icon sprites.
